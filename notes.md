 # Git Commands

 ## 1. `git clone <repository link>`:
 creates a local project based on the link provided of the (remote repository)

 ## 2. `git remote -v`:
 displays the link to the remote repository

 ## 3. `git push`:
 pushes commits made in the local repository to remote/central, so other collaborators can access them

 ## 4. `git fetch`:
 fetches recent changes made by other collaborators in the remote to local

 ## 5. `git add .`:
 adds all the file changes to the staging area

 ## 6. `git commit`:
 allows us to create a commit

 ## 7. `git log`:
 gives us an overview of commits

 ## 8. `git add <filename>`:
 adds one or more files to staging

 ## 9. `git reset <filename>`:
 removes one or more files from staging

 ## 10. `git branch`:
 displays available branches

 ## 11. `git branch <branchname>`:
 creates new branch

 ## 12. `git checkout` <branchname>:
 switches to a different branch

 ## 13. `git status`:
 give status of staged/unstaged files

 ## 14. `git show <commit hash>`:
 give extensive commit info 

 ## 15. `git show --name-only <commit hash>`:
 give shorthand commit info (only the file names)

 ## 16. `git reflog`:
 give info about all commits on all branches

 ## 17. `git pull`:
 retrieves commits from central repository the local project

 ## 18. `git revert <commit hash>`:
 creates a new commit to undo changes

 ## 19. `git reset --soft <commit hash>`:
 removes commits from history keeps changes

 ## 20. `git reset --hard <commit hash>`:
 removes commits from history and removes changes

# Commit:

- set of saved repo changes
- a commit is never lost
- a commit has a hash key
